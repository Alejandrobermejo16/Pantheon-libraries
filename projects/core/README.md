# @pantheon/core

Core services and base components for Pantheon framework.

## Features

- **PantheonRestService**: HTTP service for REST API calls
- **PantheonBaseComponent**: Base component with lifecycle hooks
- **RolesBaseComponent**: Role-based component example

## Installation

```bash
npm install @pantheon/core
```

## Usage

```typescript
import { PantheonRestService, PantheonBaseComponent } from '@pantheon/core';
```
